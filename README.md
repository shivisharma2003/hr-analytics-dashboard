# 👥 HR Analytics Dashboard

An interactive HR Analytics Dashboard built with Python and Streamlit, analyzing the IBM HR Employee Attrition dataset.

## 🔗 Live Demo
👉 [hr-dashboard-shivi.streamlit.app](https://hr-dashboard-shivi.streamlit.app)

## 📊 Features
- **Attrition Analysis** — Department-wise and age-group attrition breakdown
- **Salary Analysis** — Distribution by department and job role
- **Performance Analysis** — Ratings across departments
- **Diversity Insights** — Gender and education distribution
- **Correlation Heatmap** — Feature relationships
- **Key Insights** — Auto-generated business insights
- **CSV Upload** — Works with any HR dataset
- **Download** — Export filtered data

## 🛠️ Tech Stack
- Python
- Pandas
- Plotly
- Streamlit

## 📁 Dataset
IBM HR Analytics Employee Attrition Dataset
- 1,470 employee records
- 35 features

## 🚀 Run Locally
```bash
git clone https://github.com/shivisharma2003/hr-analytics-dashboard
cd hr-analytics-dashboard
pip install -r requirements.txt
python -m streamlit run app.py
```
